# Phase 6 — My Time Page

**Date:** 2026-05-04
**Branch:** main

## Overview
Implemented the "My Time" tab under the Time Keeping section. Employees can view their live clock widget alongside a paginated monthly history of their time logs.

**`history()` method:**
- Accepts `?month=YYYY-MM` query param (defaults to current month)
- Scoped strictly to `auth()->id()` — no policy needed
- Returns `TimeLogResource::collection()` paginated (31 per page)
- Falls back to current month if month param is invalid

## Architecture Decisions

- **Month navigation** stored as `year` + `month` integers (1-based). Computed `YYYY-MM` string on each query. "Next" disabled when viewing the current month.
- **`ClockWidget` reused as-is** — same props (`timelog`, `schedule`, `isLoading`); fetches its own break config internally.
- **`scheduleApi.useGetMyScheduleQuery`** — passes the employee's schedule to `ClockWidget` for shift display.
- **Polling** — `getToday` polled every 30 s so elapsed time reflects fresh data without full page reload.
- **Empty state** — Clock icon + "No records this month" when API returns empty array.
- **Loading state** — Ant Design `Skeleton` rows rendered in place of table.
- **Status badges** — colour-coded: active (emerald), on_lunch (amber), on_break (sky), clocked_out (slate).
- **`total_worked_minutes`** — rendered as indigo chip `7h 30m`; raw minutes from `TimeLogResource`.
